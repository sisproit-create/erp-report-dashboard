# SAS SmartPlant Executive Portal V5 Enterprise

## Incluye
- Rutas independientes por módulo.
- Navegación móvil tipo drawer con overlay, bloqueo de scroll y safe areas para iPhone.
- Uso de `100dvh` para corregir saltos de altura móvil.
- Textos de interpretación gerencial dentro de Producción, Combustible, AC30/Laboratorio, Equipos, Costos, Reportes y Alertas.
- Reportes ordenados del más reciente al más antiguo usando `created_at` y como respaldo `fecha_publicacion`.
- Fecha y hora visibles en cada tarjeta de reporte.

## Instalación
```bash
npm install
npm run build
```

## Publicación
```bash
git add .
git commit -m "SAS SmartPlant Executive Portal V5 Enterprise"
git push origin main
```
